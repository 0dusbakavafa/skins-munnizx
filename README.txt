FISH MOD Z · WARDROBE STUDIO (versão modernizada)

COMO USAR
1. Extraia todo o ZIP mantendo a estrutura de pastas.
2. Abra index.html para uma visualização local (alguns navegadores restringem recursos locais; para melhor compatibilidade, publique a pasta em um host estático HTTPS).
3. Para publicar, envie o conteúdo completo da pasta para o seu host.

MANTIDO
- Catálogo de itens e seletores de roupa.
- Pré-visualização e lógica de combinação.
- Exportação de uma versão e de quatro versões, usando os dados capturados no arquivo original.
- CSS, ícones e recursos incluídos no arquivo arquivado.

REMOVIDO
- Script de pontos fish-export-points.js.
- Chamadas de verificação/cobrança de pontos na lógica de exportação.
- Links de conta, autenticação de retorno e recebimento de pontos no menu.

LIMITAÇÕES CONHECIDAS
- A captura do Web Archive pode não conter todos os recursos do site original.
- Os dados e a pré-visualização dependem dos recursos que estavam no arquivo enviado.
- A versão foi verificada estruturalmente; o comportamento 3D e a exportação precisam ser testados em navegador real e no host final.
